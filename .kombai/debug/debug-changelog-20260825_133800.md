## Changes Made

### 1. Replaced Gmail OAuth2 delivery with SMTP-only delivery
- **File:** `backend/utils/email.py`
- **Change:** Removed Gmail API/OAuth imports and sender logic. Added `smtplib` delivery for both the admin notification and student confirmation.
- **Why:** The enquiry flow must use SMTP only; OAuth refresh/API calls were causing the deployed request to hang and time out.
- **Revert:** Restore the prior Gmail API sender and imports.

### 2. Added Gmail TLS mode support and bounded SMTP operations
- **Files:** `backend/utils/email.py`, `backend/config/config.py`
- **Change:** Supports Gmail port `587` with STARTTLS and port `465` with implicit SSL. Uses `SMTP_TIMEOUT=5` by default and closes failed connections safely.
- **Why:** Prevents a blocked/unavailable SMTP connection from consuming the browser request timeout.
- **Revert:** Restore the previous single SMTP mode/default timeout.

### 3. Kept branded HTML email behavior
- **File:** `backend/utils/email.py`
- **Change:** Preserved the two professional HTML templates and restored inline CID logo embedding with the public URL fallback.
- **Why:** Switching transport must not remove the existing email design or logo compatibility.
- **Revert:** Use the previous template/logo implementation.

### 4. Made email delivery failure explicit
- **Files:** `backend/routes/enquiry.py`, `frontend/src/services/enquiryService.js`
- **Change:** Runs the blocking SMTP route as a normal FastAPI sync endpoint, returns `503` for SMTP delivery failures, and increases the frontend request ceiling to 45 seconds so it can receive the backend response.
- **Why:** A delivery failure is not a database `500`, and the frontend should show the safe SMTP error returned by the API.
- **Revert:** Restore the async route, prior status/detail, and 30-second request ceiling.

### 5. Removed obsolete OAuth setup
- **Files:** `backend/requirements.txt`, `backend/get_gmail_token.py`, `backend/get_refresh_token.py`, `backend/.env.example`, `backend/.env`
- **Change:** Removed OAuth-only dependencies/helpers/configuration and documented `EMAIL_PASSWORD`, `SMTP_PORT`, `SMTP_TIMEOUT`, and `SMTP_USE_SSL`.
- **Why:** Keeps SMTP as the only supported delivery contract and avoids accidentally configuring the unused OAuth path.
- **Revert:** Restore the OAuth dependencies, helper scripts, and OAuth environment values.
