## Changes Made

### 1. Added bounded SMTP operation timeout
- **File:** `backend/config/config.py`
- **Change:** Added `SMTP_TIMEOUT` with an 8-second default.
- **File:** `backend/utils/email.py`
- **Change:** Applied `settings.SMTP_TIMEOUT` to the Gmail SMTP connection.
- **Why:** Prevents the deployed request from hanging until the frontend's 30-second abort timeout.
- **Revert:** Remove `SMTP_TIMEOUT` from settings and restore the SMTP timeout literal.

### 2. Improved safe SMTP diagnostics
- **File:** `backend/utils/email.py`
- **Change:** Added separate handling for Gmail authentication failures, connection/timeouts, and unexpected SMTP errors. Logs never include the password.
- **Why:** A deployed `503` now produces an actionable server log without exposing credentials to the browser.
- **Revert:** Restore the single generic SMTP exception handler.

### 3. Rejected placeholder App Password values
- **File:** `backend/config/config.py`
- **Change:** Treats `YOUR_GMAIL_APP_PASSWORD` and `YOUR_APP_PASSWORD` as missing credentials.
- **Why:** Prevents deployment from attempting SMTP login with an example value.
- **Revert:** Return the raw normalized `EMAIL_PASSWORD` value.

### 4. Documented deployment configuration
- **Files:** `backend/.env.example`, `README.md`
- **Change:** Added `SMTP_TIMEOUT=8` and explicit hosting-provider variables.
- **Why:** Makes the Render/deployment environment contract explicit.
- **Revert:** Remove the added deployment-variable documentation.
