## Changes Made

### 1. Added missing SQLAlchemy backend dependency
- **File:** `backend/requirements.txt`
- **Change:** Added `SQLAlchemy==2.0.52` to the backend dependency manifest.
- **Why:** `backend/database/database.py` imports SQLAlchemy before FastAPI can start. The package was missing from the manifest and the active environment, leaving port 8000 unavailable and causing Vite's `/api` proxy to surface a 500 error.
- **Revert:** Remove the `SQLAlchemy==2.0.52` line only if the backend no longer uses SQLAlchemy.
